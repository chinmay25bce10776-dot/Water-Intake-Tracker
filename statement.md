# Problem Statement
Many people forget to track their daily water intake, which leads to dehydration, low energy, and poor focus.  
There is no simple tool that allows users to record their daily water consumption in different units  
(glasses, ml, or litres) and compare it with a target.

This project aims to build a simple Python-based Water Intake Tracker that helps users  
monitor their hydration throughout the day.

# Scope of the Project
- The program will take water intake inputs for:
  - Morning
  - Afternoon
  - Evening  
- Users can choose between *three modes*:
  - Glasses  
  - Millilitres (ml)  
  - Litres  
- The system will:
  - Convert all inputs to litres  
  - Calculate total daily intake  
  - Compare it with user’s daily target  
  - Display hydration status  
  - Save the record in a history file  
  - Allow users to view previous entries  

The project covers basic Python syntax,functions,conditions,and file handling.

# Target Users
- Students  
- Working individuals  
- Fitness focused users  
- Anyone who wants to maintain proper hydration  
- People who prefer simple, text-based tracking tools  

# High-Level Features
- Three input modes: Glass, ml, Litre  
- Morning, Afternoon, Evening intake system  
- Automatic conversion to litres  
- Hydration level analysis:
  - Very Low  
  - Low  
  - Almost Reached  
  - Target Achieved  
  - Over Drinking
- File-based history saving (water_history.txt)  
- Option to view full history
